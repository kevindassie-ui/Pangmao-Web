# Pangmao Web · 胖猫

Prototype installable « 我学法语 » destiné à une première validation sur
iPhone. Il propose un dictionnaire français–chinois bidirectionnel, des fiches
lexicales, la prononciation française et des favoris locaux.

Utiliser le prototype: <https://kevindassie-ui.github.io/Pangmao-Web/>

Sur iPhone, ouvrir cette adresse dans Safari puis choisir **Partager → Sur
l'écran d'accueil**. Le dictionnaire est chargé au premier démarrage et peut
ensuite être réutilisé hors ligne.

Ce dépôt public contient uniquement les fichiers statiques nécessaires au
déploiement. Le développement principal et l'application Android restent dans
un dépôt privé distinct.

Version déployée depuis le commit Pangmao `bda807f`.
