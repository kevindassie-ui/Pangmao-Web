# Pangmao — French voice comparison, revision 3, 8 October 2026

These twenty-four files are **synthetic speech**, not recordings of the speakers.
They are an experimental comparison, not a claim of accepted pronunciation
quality or a complete dictionary/Reader voice service.

## Generation only

Piper 1.4.1 (OHF-Voice, GPL-3.0) and ONNX Runtime run only in the generation
environment. No Python runtime, executable or model weights are distributed
in this page. ONNX Runtime telemetry is disabled before initialization with
`ORT_DISABLE_TELEMETRY=1`, then via its Python API.

The fixed French texts are original Pangmao test sentences, not user content.
`tools/generate_web_voice_trial.py` records input hashes, speaker IDs, duration,
generation time and output SHA-256 in `manifest.json`. Speech is rendered at
the model's normal length scale, encoded in mono MP3 at 64 kbit/s, and never
regenerated by ordinary CI. No subscription or inference service is involved.
The procedure is reproducible; byte-identical inference across runtime/platform
versions is not guaranteed. The distributed files are checked by their hashes.

## Pronunciation corrections in revision 3

The displayed French sentences are unchanged. Before synthesis, valid clock
forms such as `18 h 30` become `18 heures 30`. The reviewed phrase
`je voudrais acheter` uses explicit Piper phonemes `ʒə vudʁˈɛ aʃətˈe`, retaining
the schwa in `acheter` and avoiding the automatically added consonant after
`voudrais`. This is a targeted test-phrase correction, not a general French
liaison rule. See [Piper's raw-phoneme support](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md#raw-phonemes).

The manifest records displayed, spoken and synthesis inputs separately. Four
clips (numbers and purchase sentence, both speakers) were regenerated; the
other eight retain their original hashes and generation version. The revised
audio still needs confirmation by listening to the two reported passages.

  Its gender profile is unassigned; no gender or regional accent is inferred

Both models use the same pinned `rhasspy/piper-voices` revision as UPMC.
Voice-specific model cards, all input SHA-256 hashes and actual synthesis
settings are recorded under `models` / `voices` / `clips` in the manifest.
Synthetic speech generation and MP3 compression are Pangmao's modifications;
these new outputs are also distributed as part of this CC BY-SA 4.0 audio
collection, with the above CC BY 4.0 source attributions retained.

For each new clip, the generator decodes the MP3 and requires an identical
number of PCM samples to the source WAV. This detects encoding truncation,
not mispronunciation or dropped sounds inside neural synthesis. Perceived
accuracy and naturalness require listening; none of these candidates has
been accepted for dictionary or free-text Reader integration.
