# Pangmao — French voice comparison, 7 October 2026

These twelve files are **synthetic speech**, not recordings of the speakers.
They are an experimental comparison, not a claim of accepted pronunciation
quality or a complete dictionary/Reader voice service.

## Generation only

Piper 1.4.1 (OHF-Voice, GPL-3.0) and ONNX Runtime run only in the generation
environment. No Python runtime, executable or model weights are distributed
in this page. ONNX Runtime telemetry is disabled before initialization with
`ORT_DISABLE_TELEMETRY=1`, then via its Python API.

The fixed French texts are original Pangmao test sentences, not user content.
`tools/generate_web_voice_trial.py` records input hashes, speaker IDs, duration,
generation time and output SHA-256 in `manifest.json`. Speech is rendered at
the model's normal length scale, encoded in mono MP3 at 64 kbit/s, and never
regenerated by ordinary CI. No subscription or inference service is involved.
The procedure is reproducible; byte-identical inference across runtime/platform
versions is not guaranteed. The distributed files are checked by their hashes.
