没有声音？安装法语声音

Android：设置 → 无障碍（或“更多设置”）→ 文字转语音输出 → 安装语音数据 → 法语（法国）。安装后从 Chrome 或主屏幕重新打开胖猫。

iPhone：设置 → 辅助功能 → 朗读内容 → 声音 → 法语 → 下载一个法国法语声音。安装后重新打开胖猫。

不同手机的菜单名称可能略有差异。微信、聊天软件等内置浏览器有时不会返回系统声音；此时请改用 Safari、Chrome 或已安装到主屏幕的胖猫。

胖猫会在点击朗读时再次等待系统加载声音，而且只接受明确标记为法语的声音，不会退回中文声音。可用声音由 Safari、Chrome 和手机系统提供。

基础词典来自 FreeDict、WikDict、Wiktionary 和 DBnary 贡献者；部分中文解释来自中文维基词典贡献者，并经 Kaikki / Wiktextract 提取；经复核的缺词补充来自 CFDICT 和胖猫人工校订。推测释义始终单独标记，不会冒充直接词典释义。
